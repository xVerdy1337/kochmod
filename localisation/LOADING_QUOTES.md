# Свои загрузочные цитаты

Основной файл для русского языка: `russian/replace/koch_loading_tips_l_russian.yml`.
Стандартные загрузочные цитаты отключены во всех десяти языках игры.

Чтобы добавить свою цитату, заполните одну из пустых строк:

```yaml
 LOADING_TIP_0:0 "Текст вашей цитаты.\n— Автор"
```

В файле уже подготовлены слоты `LOADING_TIP_0`–`LOADING_TIP_162`.
Заменяйте пустые значения, сохраняя номера ключей, заголовок языка и кодировку UTF-8 с BOM.
Для перевода заполните тот же ключ в соответствующем языковом файле
`<язык>/replace/koch_loading_tips_l_<язык>.yml`.

Пока слоты пустые, текст цитат не отображается. При заполнении части слотов
загрузка может выбрать оставшийся пустой слот. Для постоянного отображения
цитат заполните все слоты; повторять одну цитату в нескольких слотах можно.
После изменения файлов полностью перезапустите игру.
